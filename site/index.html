The idea

The task is the source of truth.

Most task apps make you rebuild today from yesterday. Notes & Goals has no daily page at all — Today is a live view of every task you haven't finished.

Mark something done or dropped and it's gone. Leave it open and it keeps showing up, quietly getting older, until you deal with it. Carry-forward is automatic; there's no migration step, ever.

Some days need more than a queue. Commit up to five tasks to today's slate, office and personal mixed as you like, and finish them. That's the day's only finish line — no points, no streaks, no penalties.

What's inside

Plan it, write it, finish it.

A slate for the tasks that matter today, a real editor for the thinking around them, and goals that keep score for you.

Today

Scratchpad ⌘J

Get it out of your head, then get back to work.

A floating brain-dump pad that opens over whatever you're doing. Drag it anywhere, resize it, and keep separate scraps in tabs.

  • ⌘T for a new tab, ⌘1–⌘9 to jump between them.
  • Insert the time, copy a tab, or clear it in one click.
  • Stays on this Mac — never written to your data folder.

Notes

Write in a real editor. Keep plain Markdown.

Headings, lists, checklists, quotes and dividers as you type — saved as a .md file any editor can open.

  • Notebooks for Office and Personal, with drag-and-drop filing.
  • Links open in your browser on ⌘-click.
  • Smart punctuation: -- becomes —, ... becomes ….

  • Goals

    Longer-term aims whose progress comes from the tasks you link. Nothing to update by hand.

  • Search ⌘K

    Find tasks, goals, notebooks and words inside notes, then jump straight there.

  • Activity

    Look back at what you created and finished on any day. No journaling required.

  • Office / Personal filter on every view
  • Light and dark themes
  • Settings ⌘, to change or reveal your data folder

Your data

Everything you write lands in a folder you choose, as files you can read without the app — Markdown for notes, JSON for tasks and goals. Point at a line on either side to find its twin.

Install

Four steps and you're working.

  1. 1

    Download the .dmg

    One universal build that runs natively on Apple Silicon and Intel Macs.

  2. 2

    Drag to Applications

    Open the disk image and drag Notes & Goals.app into Applications.

  3. 3

    Approve it once

    Double-click the app and click Done on the warning. In System Settings → Privacy & Security, click Open Anyway and enter your password.

  4. 4

    Choose a data folder

    Pick where your tasks, notes and goals live. Change it later in Settings ⌘,.

Why the extra step? Builds aren't notarized by Apple yet, so macOS says it can't verify the app. Open Anyway appears in Privacy & Security for about an hour after your first try, and approves the app for good. Prefer Terminal? xattr -dr com.apple.quarantine "/Applications/Notes & Goals.app" does the same. A new version may ask again; your data folder is never touched.

FAQ

Before you download.

Is it really free?

Yes. Notes & Goals is MIT-licensed open source — no paid tier, no trial, and no account.

Can I use it on more than one Mac?

Put your data folder in iCloud Drive, Dropbox or a git repo and choose it on each Mac. The app picks up changes when you switch back to its window. It doesn't merge edits itself, so avoid changing the same item on two Macs at once.

Why does macOS say it can't verify the app?

Notarizing needs a paid Apple Developer account, which this project doesn't have yet. Approve the app once, as shown in Install, and it opens like any other app from then on.

Where does the scratchpad keep its text?

On that Mac only, inside the app — never in your data folder. It's for scraps in flight, so it doesn't sync.

What happens to my data if I stop using it?

Nothing. Tasks and goals are JSON files and notes are Markdown, all in your folder. Open them in any editor, or point another tool at them.

Is there an iPhone, Windows or web version?

Not today — Notes & Goals is a Mac app. The source is on GitHub if you'd like to follow along.

Build it yourself

Tauri 2 and React on top, Rust underneath owning every file write. Needs Rust, Node 18+ and the Xcode Command Line Tools.

$ git clone https://github.com/Ashishjain608/notes-goals-app.git
$ cd notes-goals-app && npm install
$ npm run tauri:dev
